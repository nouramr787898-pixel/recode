# لقطة — موقع تصوير نافذة أو شاشة مع تحديد جزء

1. افتح مستودع GitHub الذي نشرت عليه الموقع.
2. ارفع ملفات `index.html` و`style.css` و`script.js` و`README.md` في جذر المستودع (وليس داخل مجلد إضافي).
3. في Settings → Pages، اختر Deploy from a branch ثم main و /(root).
4. انتظر اكتمال النشر ثم حدث موقعك بـ Ctrl+F5.
5. اضغط «اختيار شاشة أو نافذة أخرى»، واختر شاشة كاملة أو تبويب/نافذة موقع آخر (لا تختَر صفحة لقطة نفسها).
6. بعد العد التنازلي، ارجع إلى صفحة لقطة واضغط «تحديد جزء»، واسحب الماوس ثم «حفظ الجزء المحدد PNG».

ملاحظات: لا يُمكن لموقع ويب عادي أن يعرض شريط أدوات عائم فوق جميع نوافذ Windows أو يصور الشاشة دون موافقة المستخدم. هذا الموقع يلتقط لقطة ثابتة بعد السماح المؤقت بالمشاركة، ويتوقف عن المشاركة فورًا بعدها. بعض المحتوى المحمي قد يظهر أسود أثناء المشاركة. لا يتم تحميل الصورة إلى خادم.
