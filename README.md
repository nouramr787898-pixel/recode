# Screenshot Website - موقع لقطة

موقع مجاني لالتقاط **صور PNG فقط** من شاشة كاملة أو نافذة معينة، مع قص جزء محدد باستخدام الماوس. لا يوجد تسجيل فيديو أو صوت ولا رفع لصورك لخادم.

## رفع الموقع على GitHub Pages
1. افتح المستودع `recode` على GitHub ثم تبويب **Code**.
2. احذف أو غيّر اسم ملف `index (1).html` القديم لتجنّب الالتباس.
3. ارفع الملفات الثلاثة **index.html** و **style.css** و **script.js** إلى جذر المستودع (وليس داخل مجلد فرعي)، ويمكنك رفع README.md أيضًا.
4. Settings > Pages > Build and deployment: اختر **Deploy from a branch**، ثم `main` و `/(root)`، واضغط Save.
5. انتظر انتهاء عملية النشر في تبويب Actions، وافتح `https://nouramr787898-pixel.github.io/recode/` مع تحديث قوي Ctrl+F5.

مهم: لا ترفع ZIP مباشرة إلى المستودع؛ فك الضغط أولاً وارفع الملفات الموجودة **داخله**.

## الاستخدام
1. اضغط **التقاط صورة جديدة**.
2. في نافذة Chrome/Edge اختر نافذة أو شاشة واضغط **Share/مشاركة**.
3. ستلتقط الأداة إطارًا واحدًا فقط وتوقف مشاركة الشاشة تلقائيًا.
4. اسحب على المعاينة لتحديد مستطيل ثم اضغط **حفظ الجزء المحدد**، أو احفظ الصورة كاملة.

الموقع يحتاج HTTPS أو localhost لاستخدام getDisplayMedia. لا يمكنه التقاط جزء خارج إطار الشاشة/النافذة التي اخترتها، وبعض الصفحات المحمية قد تظهر سوداء.
